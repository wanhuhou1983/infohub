## 晚间追加：P1 部署打通（云端采集已实跑）

### 跨境拉镜像的最终解法
GHCR → 腾讯云 `docker pull` 大层反复 `unexpected EOF`（单次 12 分钟，重试也慢）。
新增 `.github/workflows/cloud-deploy-fast.yml`：`git archive HEAD` 打包源码（几 MB，自动排除 .env/data）→ scp 到云端 → 用 `FROM ghcr.io/...:latest` + `COPY backend/ /app/` + `COPY frontend/ /app/frontend/` 在**云端本地**覆盖构建（秒级，零大层下载）→ 生成 env-file → 重建容器。
配套 `.github/workflows/cloud-ops.yml`（workflow_dispatch：status / ensure-services / deploy）作为不依赖本机 SSH 的云端运维入口。
踩坑：scp-action 的 `source` 必须是工作区相对路径（绝对路径会打空包）；`--env-file` 生成的 600 root 文件需 `chown $(id -u)`，否则 docker CLI 读不到。
